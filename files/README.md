Place your public CV here as `CV.pdf`.

Then add this link below the main heading in `cv.html`:

```html
<p><a href="files/CV.pdf">Download CV (PDF)</a></p>
```

The existing CV page already displays a short online CV.

To have the navigation open the PDF directly (as in the reference site), replace
`href="cv.html"` with `href="files/CV.pdf"` in all three HTML pages after adding the PDF.
